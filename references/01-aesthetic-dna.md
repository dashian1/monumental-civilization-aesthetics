# 01｜参考蒸馏与美学DNA

## 证据分级

本技能来源于用户提供的文字对话与提示词，不包含这些提示词实际生成的图。以下“偏好”仅覆盖该系列创作，不推及用户所有项目。

| 证据 | 可以推导 | 不能推导 |
| --- | --- | --- |
| 用户要求保持巨物并换风格 | 巨物尺度差是稳定骨架，世界观可变 | 永远只画圆环、巨像或极远景 |
| 用户偏好有人的叙事方向 | 人与环境的关系重要 | 每张必须东方剑客、长袍、背影 |
| 用户认为潮汐圣骸不吸睛并要求停止 | 该方向在本系列进入默认避让 | 用户拒绝所有蓝色、海洋或骨质材料 |
| 用户继续要求“新的” | 需要持续差异化 | 前一套已获明确肯定或已验证转化效果 |
| 历史助手说“最推荐01/03/07” | 是助手选稿建议 | 是用户选定或市场验证 |
| 提供多组MJ参数 | 需要参数与条目一一对应 | 所有版本兼容，数值有精密因果证据 |

## 七层拆解

1. 情绪：从敬畏、孤独、未知、命运压力、探索欲中选主次。不要同时追求欢乐、恐怖、治愈、肃穆。
2. 第一眼轮廓：用不超过12个中文字说明，例如“断裂悬塔”“倒悬山脊”“银色巨手”。删去材质词后仍应有清楚结构。
3. 材料机制：主材表面、内部、边缘、接缝、风化方式各写一项。给出受光行为，不只写贵重材质名。
4. 光色：画面最大色块、次色、最亮点、暖色锚点分别在哪。黑色材料也应有表面可读性。
5. 尺度证据：人物、路径、桥、门、云带、地平线之间如何互相证明大小。
6. 行为：谁正在趋近什么、避开什么、等待什么。无需完整剧情，只需一个可冻结的瞬间。
7. 媒介：概念绘画、风格化三维、实拍感必须区分。用体积、表面和光影说明表现，不仅说cinematic。

## DNA记录格式

- 不变量：极小人物/主巨物/强尺度/电影空间/统一材料。
- 项目锁定：本项目的画幅、媒介、人物、色谱、禁止项。
- 可变项：十张图的主体拓扑、地形、动作、机位、时间与局部天气。
- 禁止回流：本轮用户明确拒绝的方向与具体原因。
- 未验证：画面是否吸睛、参数是否适合用户实际模型、图像是否满足比例。

## 从形容词变成画面约束

| 抽象词 | 可执行改写 |
| --- | --- |
| 巨大 | 门下有人行阶梯，阶梯在门柱旁像细线，巨物顶端穿过低云 |
| 神圣 | 巨大留白、低噪声表面、轴线或节律、人物克制；无需宗教符号 |
| 高级 | 限制主材数量、边缘工艺明确、光色受控、焦点清楚 |
| 吸睛 | 主体剪影完整、明暗分离、暖冷锚点、一处违反常识的结构 |
| 电影感 | 前景遮挡、中景行为、背景威胁、可解释的光源、视线走向 |
| 文明感 | 同样结构语法用于桥/服装扣件/仪器/交通，不依靠堆建筑 |
| 非写实但有3D味 | 雕塑式体积、接触阴影、材质粗糙度差异、受控反射、绘画式表面 |

## 吸睛诊断

先问“缩成很小的图，还能不能读出巨物轮廓和人的位置”。若不能，优先减少次要结构、拉开亮度和色相、重排尺度；不先加闪电、粒子和饱和度。没有实际图时这只是构图设计预检，不宣称已通过缩略图测试。
