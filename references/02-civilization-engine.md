# 02｜文明生成引擎

## 从情绪到世界规则

用这个链条设计：情绪目标→物质特性→结构生长方式→能量/自然现象→人类适应→画面母题。先让因果可理解，再命名。

例：危险的敬畏→铜与玄武岩分段悬浮→构件按磁力场保持距离→电弧只跨越断口→人走绝缘石道、使用场强仪→一个人停在正在分离的桥端。它比“铜色赛博神殿”更能产生新镜头。

奇幻机制是创作规则，不伪称科学事实。可说“虚构的场力维持悬浮”，不说真实磁场必然能托住任意石城。

## 风格卡：完整模式必填

| 字段 | 设计内容 |
| --- | --- |
| 名称 | 材质/现象/文明关系组合，避免只靠词藻 |
| 一句话钩子 | 一个可看见的世界规则，不写抽象宣传 |
| 主情绪/次情绪 | 各一个；说明人物如何体验 |
| 主材料 | 表面质感、受光方式、边缘、老化 |
| 辅材料 | 提供承重/连接/反射对比，不与主材争位 |
| 形态语法 | 例如悬片、折壳、切槽、桁架；明确连接方式 |
| 能量或异常规则 | 现象出现的位置、颜色、强弱与限制 |
| 巨物类别 | 建筑、工具、地貌、实体、交通系统中的主类 |
| 地表与天空 | 地面可通行性、地平线、空气环境 |
| 色谱 | 主色/辅助/强调，配上各自承担对象 |
| 布光 | 主光来源与方向、补光方式、最暗处可读性 |
| 人物 | 身份、衣料、动作动机、与环境的尺度关系 |
| 文明生活证据 | 路径、修补、运输、导航、维护中的2—3项 |
| 禁止项 | 针对该方向最可能跑偏的3—5项 |
| 稳定英文锚点 | 5—8个可放入每条的具体短语 |

## 材料推导表

| 材料 | 可见行为 | 可转成结构 | 失真风险 |
| --- | --- | --- | --- |
| 漆 | 深色平面、锐利反光、磨损露底 | 连续台面、弧墙、嵌板 | 满屏油亮黑，细节消失 |
| 螺钿 | 薄片、角度虹彩、嵌入表面 | 星图嵌线、接缝标记 | 变成发光霓虹或普通玻璃 |
| 瓷 | 冷白体积、薄边透光、裂釉 | 壳体、拱、叠片 | 变成骨骼、廉价塑料或灰泥 |
| 琥珀 | 树脂包裹、透光、内含物 | 膜壳、囊室、封存结构 | 通体橙色玻璃城堡 |
| 液态银 | 镜面扭曲、连续流面、收缩边界 | 倒山、裂月、巨手、流桥 | 镀铬汽车质感或反射噪声 |
| 氧化铜 | 哑光铜绿、暴露铜边、雨痕 | 分段板、悬梁、裂塔 | 普通绿色石头、霓虹机甲 |
| 纤维/纸 | 层理、纤维边、折痕、半透光 | 折板地貌、悬膜、层叠断崖 | 缺失巨大空间，退成桌面模型 |

这些是创作推导示例，不是必须全用的风格菜单。

## 新风格搜索法

内部提出最多三个候选即可：每个一句视觉规则，配材料行为、拓扑、空间和色谱。和最近2—3套及台账比较，剔除最相似者。优先选一套可扩展出十种具体处境的方向。

判定“只换皮”：仍然小人站在同一居中圆门前，仅铜换成银、天色换成红；这是变体，不能自称全新方向。保留某一个旧元素可以，但应明确其它变化。

避免将“新”理解为越来越复杂。让新材料改变重力关系、交通形式、地形切面或光线传播，比增加神像数量有效。

## 文化与原创设计

采用东方、藏式、东欧等文化参考时，指定屋面节律、构件、材料、地貌、服饰轮廓等可描述内容。虚构混合物标记为“受某文化启发的幻想文明”；不编造真实习俗或历史。若需要实际知识准确性，应另查可靠资料。

默认用原创角色。人物的衣领、扣件、武器护手可以与主形态呼应，但不必把整套主材料做成衣服。液态银文明中的人可以穿哑光布，铜文明的人可以用陶瓷绝缘配件，这种对比同时有功能依据。
