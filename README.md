# monumental-civilization-aesthetics · 巨物文明美学导演

一个小人物面对巨物、原创异质文明、史诗巨构风格图的**完整美学链路**。
纯 Markdown 工作流，无脚本、无依赖、无联网要求，任何具备读文件能力的智能体都能跑。

## 它做什么

把一句题材或一组参考，变成可持续扩展的文明视觉系统，再变成每条可独立生成的图像提示词。

1. **参考蒸馏** — 把参考拆成情绪、轮廓、材料、光色、尺度、人物意图，分级为保留 / 可变 / 否定 / 未验证
2. **文明生成引擎** — 从材料行为推导结构、能量规则、空间和人的生活，而不是给城堡贴纹理
3. **尺度构图** — 巨物支配空间，人物提供可读标尺；五种空间组织 + 十条系列任务分配
4. **提示词编译** — 中文标题 + 英文正文 + 完整 MJ 参数，具体词优先于形容词
5. **质检与定向修复** — 两级检验（文本预检 / 实图检验），按症状定位病因，不整体重做
6. **跨智能体交接** — 自包含状态，不依赖原对话、个人记忆或私有路径

## 七条不变量

| # | 不变量 |
| --- | --- |
| 1 | **尺度关系** — 巨物支配空间，人物极小但不能消失成噪点 |
| 2 | **一个主视觉奇观** — 先读剪影，再看材质，最后读细节 |
| 3 | **人物有目的** — 接近、横渡、停步、测量、对峙，不对镜头展示服装 |
| 4 | **材料驱动文明** — 表面属性决定结构、接缝、磨损、照明与交通 |
| 5 | **受控色谱** — 少量大色块建立识别，强调色服务人物 |
| 6 | **电影空间** — 前中后景、地面接触、遮挡、光源、空气透视 |
| 7 | **系列可变且统一** — 重复材料与形态规则，改变主体拓扑与机位 |

> 电影感不等于暗、雾、黑边、8K。

## 安装

把整个目录放进宿主技能目录即可（保持相对目录，不要只拷 `SKILL.md`）：

```
~/.workbuddy/skills/monumental-civilization-aesthetics/
```

不支持的宿主可把 `SKILL.md` 与所需 `references/` 直接载入上下文。

## 用法

- 换风格：`保留极小人物和巨构，换一个和液汞、蓝铜不同的风格，统一 9:16，给 10 条完整 MJ 提示词`
- 沿用：`沿用当前风格，01—10 只要参数，顺序和数值不要改`
- 修图：`这一组太黑，只修光线与人物可读性，结构和色谱不变`
- 交接：`把这套美学交给另一个智能体继续，附锁定项、已用方向、拒绝项和未验证事项`

## 边界

不承诺爆款、点击率、全网首创、百分之百一致性或特定参数必出神图。
不捏造图片、用户点赞、风格参考编号或模型版本。没有实际出图时不宣称图像效果已验证。
